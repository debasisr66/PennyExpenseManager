PENNY EXPENSE MANAGER V3

Hosted app:
https://debasisr66.github.io/PennyExpenseManager/

To run a downloaded copy:
1. Keep all repository files and folders together.
2. In this folder, run: python3 -m http.server 8767
3. Open: http://127.0.0.1:8767/

Use Data & backups to export CSV, Excel, or a complete JSON backup.
All expense records and budgets use Indian rupees (INR / ₹).

Read README.md for the feature guide, privacy notes, and test commands.
Read TEST-CASES.md and TEST-RESULTS.md for verification evidence.
Read SECURITY-REVIEW.md for the OWASP review and remaining limits.
