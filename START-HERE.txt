PENNY 3.2 — V3.2 RELEASE

1. Start Docker Desktop.
2. From this folder: ./scripts/penny --start
3. Open http://localhost:8080/
4. Stop: ./scripts/penny --stop

Stop any other Penny container before starting this version. The existing installed penny launcher has not been changed. Alternatively run python3 -m http.server 8769 --bind 127.0.0.1 and open http://127.0.0.1:8769/.

Read README.md and V3.2-TEST-RESULTS.md. Real iPhone microphone, native-speaker and usability review remain unverified release limitations. V3.2 publication approved on 19 October 2026. Back up real expenses before moving between origins or versions.
