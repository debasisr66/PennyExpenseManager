## Evidence rules

Use automated tests for pure/state boundaries, browser fixtures for failure paths and manual inspection for interaction/accessibility/device outcomes. A screenshot alone cannot prove keyboard behavior, and a simulated transcript cannot prove speech capture. Tests require actual implementation; source review of this specification is documentation validation only.

Existing V3.1 `TEST-CASES.md`, `TEST-RESULTS.md`, TAP and browser reports remain historical until V3.2 execution is completed and documented. Add case IDs and results to the appropriate existing live reports during implementation; update the traceability status using the actual result and commit.
