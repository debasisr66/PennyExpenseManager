## Voice amount correction follow-up — 19 October 2026

User report: Hindi selected; `spend rs.50 on donation`; Amount stayed empty after Use English draft. Two gaps were corrected: prefix currency notation (`Rs.50`, `Rs. 250`, INR and common Hindi rupee forms), and the Apply handler unconditionally clearing an originally unresolved amount even after an explicit monetary correction in the English draft.

A strict reviewed-amount parser now applies one complete numeric INR amount. An unresolved source can be resolved by explicitly changing its financial evidence; punctuation or unrelated wording alone cannot approve an unchanged monetary guess. Multiple amounts, malformed grouping, foreign/negative/approximate amounts and paise ambiguity remain blocked. Donation/दान/चंदा is recognised under Other.

Browser verification on the rebuilt Docker runtime: exact phrase → `Spent 50 rupees on donation` → Use English draft → Amount `50.00`, Category `Other`, Description `donation`. A missing Hindi amount corrected to `Spent Rs. 250 on milk groceries` applied `250.00`. The final ₹50 draft was left **unsaved** for owner review. These tests used dictated text, not actual microphone audio. [Screenshot](tests/evidence/voice-amount-fix.png).

Full Node and Docker verification after this fix: 633 passed, zero failed/skipped. Device microphone/native-speaker/manual release gates above remain pending; nothing published.
