Voice lesson and remaining limitation

Offline Hindi and Spanish expense parsing works after a transcript is captured. Microphone capture still depends on the device and browser. A phone-keyboard microphone is available as a fallback; every translated draft needs review before saving.

Privacy and release practices

Records stay in browser storage; users can export backups. Input and import checks and an adversarial review support the release. These are targeted checks, not a security certification. GitHub holds code, README, test cases, results and release history.

Three next product questions

  1. Does repeated Hindi and Spanish dictation remain reliable on the target iPhone?
  2. Which unfamiliar everyday expense words should be added next?
  3. Can Docker health, security and both platform checks be recorded for a portable release?
